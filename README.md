Специально для прокрастинаторов и тех, кто забывает себя на работе за компьютером, предлагаю Богоугодное изобретение - Православный Таймер.

Разработан в том числе для личного использования, чтобы помогать сохранять баланс между работой и духовной практикой в течение дня.

📋 Функциональность
Техника Помодоро: 25 минут работы / 5 минут отдыха с автоматическими уведомлениями

Духовное наполнение:

При первом запуске каждый день - молитва "Отче Наш"

Случайные стихи из Библии и творения святых отцов каждые 4 часа

Напоминания о молитве каждые 90 минут

Учет активности: отслеживание времени работы и количества перерывов

Пауза на обед: специальная функция для длительного перерыва


⚙️ Использование
Начало дня: нажмите "Начать рабочий день"

Пауза на обед: кнопка "Обед (пауза)" для длительного перерыва

Завершение: "Закончить день" покажет статистику работы

Закрытие: при закрытии окна - духовное напоминание

🙏 Духовная составляющая
Программа создана во славу Божию и призвана помочь:

Не забывать о молитве в течение рабочего дня

Сохранять правильный ритм труда и отдыха

Наполнять ум богомыслием через священные тексты
